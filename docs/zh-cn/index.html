常见问题

使用前可能想知道这些。

需要一直开着 Cursie 吗？

不需要。应用光标后即可退出。Mac 重新启动后，Cursie 会在登录时恢复上次使用的光标。

Windows 的 .cur 和 .ani 文件能直接用吗？

可以。导入文件后，先确认每个文件对应的光标用途，再应用到 macOS。.ani 动画也可以预览。

怎样恢复 macOS 默认指针？

在 Cursie 中打开 macOS 的“指针”设置，再点“重设颜色”。Cursie 会先关闭登录时自动应用，最后的重设操作需要在系统设置中完成。

需要使用终端吗？

不需要。导入、预览、应用，以及打开默认指针设置，都可以直接在应用里完成。
