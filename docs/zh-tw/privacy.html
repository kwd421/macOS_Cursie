隱私權政策

Cursie 的所有處理都在你的 Mac 本機完成。App 不要求建立帳號、不會上傳游標檔案，也不會為了分析或廣告收集個人資料。

Cursie 會存取什麼

  • 你主動選擇的游標檔案和資料夾
  • 套用系統游標後，儲存在 Application Support 的本機主題檔案
  • 用於重新啟動後恢復游標、儲存在 LaunchAgents 的設定檔

Cursie 不會做什麼

  • 收集個人資料或使用情況
  • 跨 App 或網站追蹤你
  • 把游標檔案或其他資料上傳到伺服器
  • 未經你的操作更改系統游標

軟體更新

Cursie 使用 Sparkle 檢查新版本。檢查時只會向更新伺服器傳送目前的 App 版本，不會傳送個人資料、系統資訊或使用統計。

網站與下載統計

以上說明針對 Cursie App，App 內未加入追蹤。下載連結僅按 UTC 日期、頁面語言、連結來源、大致國家及檔案格式彙總請求數。此資料庫不儲存原始 IP、使用者代理、完整來源網址、Cookie 或個人識別碼。請求數並非不重複使用者數或下載完成數。我們也每天記錄 GitHub 公開的檔案累計下載數。Cloudflare 與 GitHub 按各自隱私權政策處理網路請求。

網站另使用 Cloudflare Web Analytics 彙總頁面瀏覽、來源網站、國家、裝置與瀏覽器類別及頁面效能。不使用分析 Cookie 或跨站識別碼。這些統計並非 App 使用量或下載完成數。
