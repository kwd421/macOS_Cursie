macOS 滑鼠游標更換工具

把 Windows 游標，直接用在 Mac 上。

用 Cursie 匯入 Windows 的 .cur 與 .ani 檔案，先確認外觀和動畫，再套用到 macOS。

下載 CursieGitHub

建議使用 macOS 15 Sequoia 或以上版本 · 支援 Apple 晶片及 Intel Mac · 免費

主要功能

匯入、預覽，然後套用。

01

匯入游標包

拖入整個資料夾，或只選擇需要的 .cur、.ani 檔案。

02

依檔名自動配對

根據 Normal、Text、Link 等名稱，自動配對一般指標、文字選取和連結游標。

03

套用前先預覽

先看看每種游標的外觀和動畫。配對不正確時，也能個別更換檔案。

04

套用到整台 Mac

套用後即可關閉 Cursie。Mac 重新啟動並登入時，先前的游標會自動恢復。

常見問題

使用前可能會想知道的事。

Cursie 需要一直開著嗎？

不需要。套用游標後就能關閉。Mac 重新啟動後，Cursie 會在登入時恢復上次使用的游標。

Windows 的 .cur 和 .ani 檔案能直接使用嗎？

可以。匯入後先確認每個檔案對應的游標用途，再套用到 macOS。.ani 動畫也能預覽。

如何恢復 macOS 預設指標？

從 Cursie 開啟 macOS 的「指標」設定，再按一下「重置顏色」。Cursie 會先停止登入時自動套用，最後的重置仍要在系統設定完成。

需要使用終端機嗎？

不需要。匯入、預覽、套用，以及開啟預設指標設定，都能直接在 App 裡完成。

最近更新

Cursie 有哪些新變化。

游標套用完成後會顯示勾選記號。按一下提示框外即可關閉。

v1.0.8

修正動畫播放速度

動畫游標現在會依照原始檔案記錄的速度播放。
