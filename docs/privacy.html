Last updated June 10, 2026

Privacy Policy

Cursie processes everything locally on your Mac. It does not require an account, upload cursor files, or collect personal information for analytics or advertising.

What Cursie accesses

  • Cursor files and folders you explicitly select
  • A local theme file saved in Application Support after applying system cursors
  • A configuration file saved in LaunchAgents so the cursor can be restored after restarting your Mac

What Cursie does not do

  • Collect personal information or usage analytics
  • Track you across apps or websites
  • Upload cursor files or other data to a remote server
  • Change system cursors without an action from you

Software updates

Cursie uses Sparkle to check for new versions. The current app version is sent to the update server during a check. Personal information, system details, and usage statistics are not sent.
