개인정보 처리방침

Cursie의 모든 처리는 사용자의 Mac 안에서 이루어집니다. 계정을 만들 필요가 없으며, 커서 파일을 업로드하거나 분석·광고를 위해 개인정보를 수집하지 않습니다.

Cursie가 접근하는 정보

  • 사용자가 직접 선택한 커서 파일과 폴더
  • 시스템 커서 적용 후 Application Support에 저장되는 로컬 테마 파일
  • Mac을 다시 시작한 뒤 커서를 복원하기 위해 LaunchAgents에 저장되는 설정 파일

Cursie가 하지 않는 것

  • 개인정보나 사용 통계 수집
  • 앱 또는 웹사이트 간 사용자 추적
  • 커서 파일이나 기타 데이터의 외부 서버 전송
  • 사용자의 동작 없는 시스템 커서 변경

소프트웨어 업데이트

Cursie는 Sparkle로 새 버전을 확인합니다. 업데이트를 확인할 때 현재 앱 버전만 업데이트 서버로 전송되며, 개인정보·시스템 정보·사용 통계는 전송하지 않습니다.

웹사이트 및 다운로드 통계

위 설명은 Cursie 앱에 관한 것이며 앱 내부 추적 기능은 없습니다. 다운로드 링크는 UTC 날짜·페이지 언어·링크 출처·대략적인 국가·파일 형식별 요청 수만 집계합니다. 이 집계 저장소에는 원본 IP, 사용자 에이전트, 전체 참조 주소, 쿠키 또는 개인 식별자를 저장하지 않습니다. 요청 수는 순 사용자 수나 다운로드 완료 수가 아닙니다. 공개된 GitHub 파일별 다운로드 누적 수도 매일 기록합니다. Cloudflare와 GitHub는 각자의 개인정보 처리방침에 따라 네트워크 요청을 처리합니다.

웹사이트는 Cloudflare Web Analytics로 페이지 조회, 유입 사이트, 국가, 기기·브라우저 분류 및 페이지 성능도 집계합니다. 분석용 쿠키나 사이트 간 식별자는 사용하지 않습니다. 웹사이트 통계는 앱 사용량이나 다운로드 완료 수와 별개입니다.
