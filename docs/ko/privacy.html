개인정보 처리방침

Cursie의 모든 처리는 사용자의 Mac 안에서 이루어집니다. 계정을 만들 필요가 없으며, 커서 파일을 업로드하거나 분석·광고를 위해 개인정보를 수집하지 않습니다.

Cursie가 접근하는 정보

  • 사용자가 직접 선택한 커서 파일과 폴더
  • 시스템 커서 적용 후 Application Support에 저장되는 로컬 테마 파일
  • Mac을 다시 시작한 뒤 커서를 복원하기 위해 LaunchAgents에 저장되는 설정 파일

Cursie가 하지 않는 것

  • 개인정보나 사용 통계 수집
  • 앱 또는 웹사이트 간 사용자 추적
  • 커서 파일이나 기타 데이터의 외부 서버 전송
  • 사용자의 동작 없는 시스템 커서 변경

소프트웨어 업데이트

Cursie는 Sparkle로 새 버전을 확인합니다. 업데이트를 확인할 때 현재 앱 버전만 업데이트 서버로 전송되며, 개인정보·시스템 정보·사용 통계는 전송하지 않습니다.
