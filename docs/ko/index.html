Windows .cur 및 .ani 커서 파일을 불러와 모양을 미리 확인합니다. 원하는 커서를 골라 macOS 시스템 커서로 적용합니다.

macOS 15 Sequoia 이상 권장 · Apple Silicon 및 Intel Mac 지원 · 무료

  • Mac 전체에 커서 적용
  • 움직이는 .ani 커서 미리보기
  • 적용한 뒤에는 Cursie를 꺼도 유지

주요 기능

01

커서팩 불러오기

커서팩 폴더를 끌어다 놓거나, 원하는 .cur와 .ani 파일만 골라 불러올 수 있습니다.

02

파일 자동 분류

Cursie가 Normal, Text, Link 같은 이름을 보고 화살표, 텍스트, 링크 커서로 알아서 나눠줍니다.

03

커서 미리보기

적용하기 전에 커서의 모양과 움직임을 미리 보고, 원하는 커서만 따로 바꿀 수 있습니다.

04

Mac에 적용

적용 버튼을 누르면 Mac의 커서가 바뀝니다. Cursie를 꺼도 커서는 바뀐 상태로 유지됩니다.

자주 묻는 질문

Cursie를 계속 켜둬야 하나요?

아니요. 커서를 적용한 뒤에는 Cursie를 종료해도 됩니다. Mac을 다시 시작하면 로그인할 때 마지막으로 선택한 커서가 다시 적용됩니다.

Windows용 .cur·.ani 커서팩도 사용할 수 있나요?

네. Windows .cur 및 .ani 커서 파일을 불러와 각 커서 역할을 확인한 뒤 시스템 커서에 적용할 수 있습니다.

움직이는 .ani 커서도 적용되나요?

네. .ani 파일의 움직임을 앱에서 미리 확인하고 시스템 커서에 그대로 적용할 수 있습니다.

원래 커서로 돌아가려면 어떻게 하나요?

Cursie의 ‘포인터 기본값 복구 열기’는 macOS 포인터 설정을 여는 버튼입니다. 설정 화면이 열리면 ‘색상 재설정(Reset Colors)’을 직접 눌러야 기본 커서로 돌아갑니다.

Cursie는 Alex Zielenski의 오픈소스 커서 도구 Mousecape를 바탕으로 만들어졌습니다.
