주요 기능

불러오고, 확인하고, 적용합니다.

01

커서팩 불러오기

폴더를 끌어다 놓거나, 원하는 .cur와 .ani 파일만 골라 불러올 수 있습니다.

02

파일 이름으로 자동 배치

Normal, Text, Link 같은 이름을 보고 화살표, 텍스트 선택, 링크 커서에 맞춰 넣어줍니다.

03

적용 전에 미리보기

각 커서의 모양과 움직임을 먼저 확인합니다. 잘못 배치된 파일은 직접 바꿀 수 있습니다.

04

Mac 전체에 적용

적용한 뒤에는 Cursie를 꺼도 유지됩니다. Mac을 다시 시작하면 로그인할 때 마지막 커서가 다시 적용됩니다.

자주 묻는 질문

사용하기 전에 알아둘 것.

Cursie를 계속 켜둬야 하나요?

아니요. 커서를 적용한 뒤에는 종료해도 됩니다. Mac을 다시 시작하면 로그인할 때 마지막 커서가 다시 적용됩니다.

Windows용 .cur와 .ani 파일을 그대로 쓸 수 있나요?

네. 파일을 불러와 어떤 커서에 배치됐는지 확인한 뒤 macOS에 적용할 수 있습니다. 움직이는 .ani도 미리 볼 수 있습니다.

macOS 기본 커서로 어떻게 돌아가나요?

Cursie에서 macOS 포인터 설정을 연 뒤 ‘색상 재설정’을 누르세요. Cursie는 로그인 시 자동 적용을 먼저 끄고, 실제 재설정은 macOS 설정에서 마무리합니다.

터미널을 사용해야 하나요?

아니요. 불러오기, 미리보기, 적용, 기본 커서 설정 열기까지 모두 앱에서 할 수 있습니다.
