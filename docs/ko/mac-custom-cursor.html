macOS 커스텀 커서 가이드

맥 커스텀 커서 적용 방법

2026년 8월 갱신 · macOS 15 이상 · Apple Silicon 및 Intel Mac 지원

맥북에서 마우스 커서의 크기나 색만 바꾸려면 macOS 설정으로 충분합니다. 화살표 모양 자체를 바꾸거나 Windows .cur·.ani 커서팩을 쓰고 싶다면 별도의 커서 적용 앱이 필요합니다.

크기·색상 변경과 커서 모양 변경은 다릅니다

macOS의 시스템 설정 → 손쉬운 사용 → 디스플레이 → 포인터에서는 포인터 크기, 윤곽선 색상, 채우기 색상을 바꿀 수 있습니다. 이 방법은 별도 앱이 필요 없고 언제든 ‘색상 재설정’으로 되돌릴 수 있습니다.

다만 기본 화살표를 픽셀 커서나 캐릭터 커서처럼 전혀 다른 이미지로 바꾸는 기능은 macOS 설정에 없습니다. 이 경우 Cursie 같은 도구로 화살표, 텍스트 선택, 링크, 대기, 크기 조절 등 여러 시스템 커서 역할을 한꺼번에 적용해야 합니다.

크기나 색만 바꿀 때

macOS 포인터 설정을 사용합니다. 가장 간단하고 시스템에서 공식 지원하는 방법입니다.

커서 그림을 바꿀 때

.cur·.ani 커서팩을 Cursie로 불러와 각 시스템 커서 역할에 적용합니다.

4단계로 커서 바꾸기

1

Cursie 다운로드 및 설치

다운로드한 DMG를 열고 Cursie를 응용 프로그램 폴더로 옮깁니다. Apple Silicon 및 Intel Mac을 모두 지원합니다.

2

커서팩 폴더 또는 파일 불러오기

.cur 및 .ani 파일이 담긴 폴더를 Cursie 창에 끌어다 놓거나, 파일 선택 메뉴에서 원하는 커서 파일을 직접 불러옵니다.

3

커서 모양과 움직임 확인

화살표, 텍스트, 링크, 대기 상태 등 각 커서 모양을 확인합니다. Normal, Text, Link, Busy처럼 용도를 나타내는 이름이 붙은 파일은 화살표, 텍스트, 링크, 대기 상태 등에 자동으로 들어갑니다. 필요한 커서만 다른 파일로 바꿀 수도 있습니다. .ani 파일은 움직이는 애니메이션을 미리 확인할 수 있습니다.

4

macOS 커서에 적용

적용 버튼을 누르면 마우스 커서가 선택한 모양으로 바뀝니다. 적용한 뒤에는 Cursie를 계속 켜둘 필요가 없습니다.

기본 커서로 되돌리는 방법

Cursie에서 macOS 설정에서 기본 커서로 재설정을 누르면 포인터 설정 화면이 열립니다. 여기서 색상 재설정을 눌러 macOS 기본 커서로 되돌릴 수 있습니다.

버튼을 누르는 즉시 자동으로 복원되는 방식은 아닙니다. macOS 설정에서 마지막 재설정 동작을 직접 눌러야 합니다.

적용이 이상할 때 확인할 것

  • 일부 커서만 화살표로 보임: 커서팩에 해당 역할의 파일이 없으면 일반 화살표가 대신 사용될 수 있습니다.
  • 텍스트 커서가 잠깐 바뀌었다 돌아옴: 일부 앱이나 웹페이지가 자체적으로 포인터 상태를 다시 지정할 수 있습니다. 다른 앱의 텍스트 입력 영역에서도 같은지 확인해 보세요.
  • 로그인 후 원래 커서로 돌아옴: Cursie로 같은 커서팩을 다시 적용하면 로그인용 적용 정보도 함께 갱신됩니다.
  • 움직임이 너무 빠르거나 어색함: 앱 미리보기에서 .ani 재생을 먼저 확인하고 다른 파일로 교체하세요.

자주 묻는 질문

Windows 커서 파일을 맥에서 쓸 수 있나요?

macOS는 Windows 커서 형식을 기본적으로 지원하지 않지만, Cursie를 사용하면 .cur 및 .ani 파일을 불러와 macOS 마우스 커서로 적용할 수 있습니다.

트랙패드와 외장 마우스 모두에 적용되나요?

네. Mac 전체의 커서가 바뀌므로 MacBook 트랙패드와 Magic Mouse는 물론, 일반 USB 및 블루투스 마우스에서도 동일하게 적용됩니다.

움직이는 애니메이션(.ani) 커서도 적용되나요?

네. .ani 파일의 움직임을 앱에서 미리 확인하고 Mac 커서로 적용할 수 있습니다.

터미널 명령을 입력해야 하나요?

아니요. 서명 및 Apple 공증된 DMG를 설치한 뒤 커서팩 폴더를 선택하고 적용하면 됩니다.

macOS Tahoe와 Sequoia에서 사용할 수 있나요?

macOS 15 Sequoia 이상을 지원하며 Apple Silicon과 Intel Mac용 코드가 함께 들어 있습니다.

Windows 커서팩을 이미 가지고 있나요?

.cur·.ani 파일 이름과 자동 배치 기준

Normal, Text, Link, Busy 같은 파일이 Mac의 어떤 커서 역할에 들어가는지 Windows 커서를 Mac에서 사용하는 방법에서 자세히 확인할 수 있습니다.
