MAC CUSTOM CURSOR GUIDE

How to change your cursor on Mac

Updated August 2026 · macOS 15 or later · Apple Silicon / Intel Mac

macOS can change the pointer size, outline, and fill color without another app.To replace the arrow itself, use a cursor app such as Cursie to import a custom pack.

Choose the kind of change you want

Change the size or color

Open System Settings → Accessibility → Display → Pointer. macOS includes controls for the pointer size, outline color, and fill color.

Change the cursor artwork

Use Cursie to replace the arrow, text-selection, link, busy, and resize cursors. It can import Windows .cur and animated .ani files.

If size and color are all you need, the built-in macOS settings are the simplest option. Use Cursie when you want to replace the cursor artwork itself.

Apply a cursor pack with Cursie

  1. Install CursieOpen the DMG and move Cursie to your Applications folder.
  2. Import a cursor packDrop in a folder containing .cur or .ani files, or select individual files.
  3. Review the mappingsCursie uses names such as Normal, Text, Link, and Busy to match cursor roles. You can replace any incorrect match manually.
  4. Preview and applyCheck the shape and animation, then click Apply. You can close Cursie after the cursor pack is active.

Restore the default macOS pointer

In Cursie, choose “Reset Default Cursor in macOS Settings.” When the Pointer settings open, click “Reset Colors.”

Cursie disables automatic reapply and opens the correct settings panel. The final reset is completed in macOS, so opening the panel alone does not immediately restore the default pointer.

If a cursor does not change

Only some cursor roles changed

The pack may not contain that role, or its filename may not identify the role clearly. Select the empty role in the preview and choose the file manually.

The pointer briefly changes back in another app

Some apps cache the cursor they were already displaying. Moving to another window or reopening the app usually refreshes it.

An .ani animation looks different from Windows

Files with unusual frame timings or repeated frames can play differently. Check the animation in Cursie before applying it.
