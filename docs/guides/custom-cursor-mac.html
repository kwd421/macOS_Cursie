macOS Custom Cursor Manual

How to Change Your Cursor on Mac

Updated Jun 2026 · macOS 15+ · Apple Silicon and Intel Mac

macOS allows basic pointer size and color adjustments in Accessibility settings. Cursie lets you import Windows .cur and animated .ani cursor packs, preview them, and use them across your Mac.

Change your cursor in four steps

1

Download and install Cursie

Open the downloaded DMG, then move Cursie to your Applications folder. It works on both Apple Silicon and Intel Macs.

2

Import a cursor pack

Drop a folder containing .cur and .ani files into Cursie, or choose individual cursor files.

3

Preview the cursors

Check how the arrow, text, link, busy, and resize cursors look. Cursie uses names like Normal, Text, Link, and Busy to sort files automatically. You can replace any cursor you want, and preview animated .ani files in motion.

4

Apply the cursor pack

Click Apply to change cursors across your Mac. You can quit Cursie afterward—the new cursors stay active.

Return to the default Mac cursor

Cursie's Open Pointer Reset button does not reset the cursor by itself; it opens macOS Pointer settings.
When the settings window opens, click Reset Colors yourself to return to the default cursor.

Frequently Asked Questions

Can macOS use Windows .cur and .ani files?

macOS does not support Windows cursor formats by default. Cursie loads .cur and .ani files and applies them directly to macOS system cursors.

Does the cursor change apply to trackpads and external mice?

Yes. It applies across macOS, so MacBook built-in trackpads, Magic Mice, and USB or Bluetooth mice all use the new cursor.

Are animated (.ani) cursors supported?

Yes. Cursie previews animated .ani files and applies them to macOS system cursors.
