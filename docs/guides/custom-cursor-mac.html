macOS CUSTOM CURSOR GUIDE

How to Use a Custom Cursor on Mac

Updated Aug 2026 · macOS 15+ · Apple Silicon and Intel Mac

macOS can change the pointer size, outline, and fill color without another app. To replace the arrow itself—or use a Windows .cur or animated .ani pack—you need a custom cursor app such as Cursie.

Choose the kind of change you want

Change size or color

Open System Settings → Accessibility → Display → Pointer. macOS already includes size, outline color, and fill color controls.

Change the cursor artwork

Use Cursie to replace the arrow, text, link, busy, and resize cursors with files from a complete cursor pack.

Change your cursor in four steps

1

Download and install Cursie

Open the downloaded DMG, then move Cursie to your Applications folder. It works on both Apple Silicon and Intel Macs.

2

Import a cursor pack

Drop a folder containing .cur and .ani files into Cursie, or choose individual cursor files.

3

Preview the cursors

Check how the arrow, text, link, busy, and resize cursors look. Cursie uses names like Normal, Text, Link, and Busy to sort files automatically. You can replace any cursor you want, and preview animated .ani files in motion.

4

Apply the cursor pack

Click Apply to change cursors across your Mac. You can quit Cursie afterward—the new cursors stay active.

Return to the default Mac cursor

Click Reset Default Cursor in macOS Settings in Cursie. This opens System Settings at Accessibility → Display → Pointer and turns off automatic reapply at login.

In that macOS panel, click Reset Colors. The reset is completed by macOS; opening the panel alone does not immediately replace the current cursor.

If a cursor does not change

  • Move Cursie to Applications before applying a pack, then approve the macOS permission prompt if one appears.
  • Check the mapping preview. Unrecognized filenames can be assigned to a cursor role manually.
  • Very large or malformed cursor files may be skipped to keep the rest of the pack usable.
  • Some apps briefly cache the pointer they already had. Moving between windows or reopening the app usually refreshes it.

Frequently Asked Questions

Can macOS use Windows .cur and .ani files?

macOS does not support Windows cursor formats by default. Cursie loads .cur and .ani files and applies them directly to macOS system cursors.

Does the cursor change apply to trackpads and external mice?

Yes. It applies across macOS, so MacBook built-in trackpads, Magic Mice, and USB or Bluetooth mice all use the new cursor.

Are animated (.ani) cursors supported?

Yes. Cursie previews animated .ani files and applies them to macOS system cursors.

Do I need Terminal commands?

No. Importing, previewing, applying, and opening the macOS reset controls are all handled from the app.

Does this work on macOS Sequoia and Tahoe?

Cursie supports macOS 15 or later, including Sequoia and Tahoe, on Apple Silicon and Intel Macs.

Already have a Windows cursor pack?

See the Windows .cur and .ani guide for Mac for filename mapping and pack-specific troubleshooting.
